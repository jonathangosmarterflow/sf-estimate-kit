Want your AI to fill in your prices?

A

Claude Code

Claude reads your notes, asks a few questions and writes the files.

  1. Open this folder in Claude Code (the terminal, the VS Code extension or the desktop app's Code tab). Nothing to install, the skill is already in the folder.
  2. Say: build my estimate funnel
  3. Open the my-funnel.html it makes.

Only Claude Code can write the files for you. Any other chat hands you settings to paste into the Studio, which is path B.

Step by step
B

Any chatbot

ChatGPT, Gemini, Claude on the web, Copilot, anything.

  1. Copy all of prompts/BUILDER-PROMPT.md into your AI chat.
  2. Answer its questions. It hands you one block of settings.
  3. In the Studio, stay on tab 1 and paste it under "Paste your AI answer here".
Open the prompt
